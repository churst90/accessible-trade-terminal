# The archive

Old plans, finished studies and closed audits live here. They are kept because they say *why* things are the way they are, and code comments and the lab's edge registry (`AccessibleTrader.StrategyLab/Catalogue/edges.json`) still point at them. They are not kept up to date: a plan here may have been built differently or not at all.

The live records are one folder up: [`TODO.md`](../TODO.md) is what is left, [`CHANGES.md`](../CHANGES.md) is what was done, [`USER_MANUAL.md`](../USER_MANUAL.md) and [`SHORTCUTS.md`](../SHORTCUTS.md) say how the app works today. Before taking up anything in a file here, check CHANGES and the code: it may have shipped since.

Moved here on 2026-11-20 at Cody's request ("Clean up old docs, studies, etc and put them in the docs/archive directory"). Every link and path that named one of them was rewritten to the new place.
