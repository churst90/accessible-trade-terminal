Accessible Trader {VERSION}, portable version for Windows

To start it, run "Accessible Trader.exe" in this folder.

The app folder holds the program and everything it needs. Keep it beside Accessible Trader.exe,
and do not move files out of it.

Nothing needs to be installed. Your settings, workspaces and logs are kept in
%LocalAppData%\AccessibleTrader, not in this folder, so you can replace this folder with a newer
version and keep them.

If you would rather install it, with a Start menu entry and an uninstaller, download
AccessibleTrader-{VERSION}-Windows-Setup.exe instead from
https://github.com/churst90/accessible-trade-terminal/releases

The program is not signed, so the first time you run it Windows may say "Windows protected your
PC". Choose "More info", then "Run anyway".

Website and help: https://accessibletrader.com
